# Monitor Tokenów — Dokumentacja

## Co to jest?
Narzędzie do śledzenia zużycia tokenów i kosztów API Anthropic w czasie rzeczywistym.

## Struktura projektu
```
Monitor-Tokenow/
├── src/
│   ├── monitor_api.py    — pobiera dane z API Anthropic
│   ├── config.json       — konfiguracja (klucz API, limity)
│   └── logger.py         — zapisuje zdarzenia do logu
├── vscode-extension/
│   ├── extension.js      — pasek statusu w VS Code
│   └── package.json      — manifest rozszerzenia
├── docs/
│   └── README.md         — ta dokumentacja
└── data/
    └── usage.log         — historia użycia (generowana automatycznie)
```
